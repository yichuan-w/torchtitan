# Changelog

## [0.2.0] - 2024-03-15

### Changed
- Migrated from setup.py-only configuration to PEP 621 pyproject.toml format
- Updated build system to use setuptools >=69
- Modernized package metadata declarations

### Fixed
- Improved error handling in validate command

## [0.1.0] - 2024-02-01

### Added
- Initial release
- csv2json command for CSV to JSON conversion
- json2csv command for JSON to CSV conversion
- validate command for data file validation
- stats command for data statistics
