# evolve-rewriter-p8: issues seen in run 1028

Run 1028 (2026-10-28) evolved on 03a648fbc, which is the canonical line plus
`evolve-rewriter-p8` @97b15bc3e. It ran 11 training steps and produced 126
rewrite outcomes before it was stopped. The run was stopped because the
local-codex route hit OpenAI's cybersecurity filter, and that is unrelated to
p8. The points below are the p8-specific findings.

## 1. Independent probe author: any incidental write fails the whole rewrite

`c178cfcf9` turned the independent probe author back on by default
(`EVOLVE_INDEPENDENT_PROBES=1`). In `evolve_codex.py` (the probe session, around
line 2740), every file outside `run/` is hashed before and after the session.
Any difference raises `RuntimeError("Independent probe author changed files
outside run/: ...")`, and the rewrite fails.

Two of 126 rewrites failed this way, and both changes look incidental:

| task | direction | changed file |
|---|---|---|
| software-engineering_20260602_105139_006 (g355) | easier 0/12 | `environment/files/repo/_git/index` |
| task_000854_fe200810 (g353) | harder 12/12 | `environment/weights.npy` |

- A git index refreshes on any `git status` or `git diff`.
- A `weights.npy` file is regenerated by running the task's own script.

Neither write tampers with the verifier. Still, each one discarded a rewrite
whose earlier stages had already run.

Suggested fixes, smallest first:

- Restore the changed files from the pre-session snapshot, keep the controls,
  and log the paths instead of raising.
- Alternatively, run the probe session on a throwaway copy of `environment/` so
  its writes never reach the package.
- If a change has to stay fatal, skip the independent probes for that rewrite
  (as `EVOLVE_INDEPENDENT_PROBES=0` does) rather than fail the rewrite.
