Assign each record exactly one hint level:
- 0 = task repair ONLY: fixes a broken/contradictory spec, an environment bug, incidental metadata, or removes a verifier check the statement never asked for. Nothing beyond making the task correct. If the rewrite ALSO gives any tool, check, or troubleshooting direction, it is NOT 0.
- 1 = added information, no method: requirement clarification, a pointer to what to check, a named diagnostic/checking tool or a troubleshooting direction, or a smaller instance/scope reduction; does not say how to do the core step. Giving a tool or a direction to investigate is at least 1.
- 2 = method given: names the method/API/function signature/command/call site, or the concrete fix, so the core diagnosis or design is handed over.
- 3a = environment does peripheral work only: the environment/Dockerfile/data now does setup or plumbing that the ORIGINAL task was not about (starting services, installing deps, fixing incidental bugs/metadata, boilerplate) while every piece the original task asked the student to build, fix, or diagnose is still left to the student.
- 3b = environment does part of the core work: the environment ships working code, a fixed component, pre-computed/pre-normalized data, or a completed step for ANY piece the ORIGINAL task asked the student to build, fix, or diagnose (e.g. "working parser supplied, execution left", "other routines supplied, division left", "starter handles lifecycle", "helper emits symbols"). Even if some core work remains, handing over part of it is 3b.
IMPORTANT: judge "core" against what the ORIGINAL (pre-rewrite) task required, i.e. the removed (-) instruction lines and the bottleneck, NOT against the rewriter's retained_skill (the rewriter always describes what is left as the core, so it is not a neutral reference).
If several apply, take the highest (order 0<1<2<3a<3b). Judge from instruction_diff + change + changed + retained_skill. Environment/solution file changes are NOT automatically 3a/3b; a fix to the task's own defect in environment files is 0, unless it also helps.
