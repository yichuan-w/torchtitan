# Overfit bench: paper workdir

Notes towards a write-up of the overfit bench and its teacher rewriter. Each file records findings
with the evidence behind them (job, step, group counts, commit), so a claim can be traced back to
the run it came from. Results themselves stay in `../tb21_results.md`; this directory holds what the
runs showed about the method.

- `findings_20261103.md`: what the 2026-11-02/03 GB300 runs showed: the solve tally and which
  solves came from training, how a teacher leaked the grading material and what stopped it, hints
  from failed attempts, the original's draw share, and the throughput limits.
